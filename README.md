# Diabetes Dataset Univariate Analysis

This project performs **univariate statistical analysis** on two diabetes datasets:
- **UCI Diabetes dataset** (`uci_diabetes.csv`)
- **Pima Indians Diabetes dataset** (`pmi_diabetes.csv`)

## 📌 Features
- Load datasets using **Pandas**
- Display sample records for quick inspection
- Perform univariate analysis on numerical columns:
  - Mean
  - Median
  - Mode
  - Variance
  - Standard Deviation
  - Skewness
  - Kurtosis
- Compare statistical summaries between UCI and Pima datasets
